# Collapse to the chat interface?
> Where are the innovations in agent interface design

For some period of time, let’s call it between 2000-2023, many startups focused on building SAAS products. You would build a product, that would give a human a new interface and they would do useful things with that interface and pay you a small fee. Has this model collapsed away from novel interfaces simply towards the ChatGPT style window?

On the one hand, the chat interface is incredibly useful. Research tasks where we already had a search box are immediately improved when you can ask a follow-up question, no arguments there. However, I do wonder if there’s missing innovation in different kinds of UX we could be exploring.

Programming is not natively a conversation, pair-coding where you talk through the code feels more natural than driving things through the chat window. Learning also appears like disruption away from the chat window to something more natural (whiteboards, slides).
